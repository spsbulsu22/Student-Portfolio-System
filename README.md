# Student Portfolio System

The **Student Portfolio System** is a web application designed to help
students organize, manage, and share their academic portfolios while
allowing instructors to manage classes and review student work.

## Purpose and Uses

-   **Portfolio Management:** Upload, organize, and manage portfolio
    files.
-   **Cloud Storage:** Store and retrieve portfolio files using Supabase
    Storage.
-   **File Sharing:** Manage portfolio file visibility and share files
    with others.
-   **Class Management:** Allow instructors to create classes, invite
    students, and manage enrollment requests.
-   **Assignments and Submissions:** Let instructors create assignments
    and review student submissions, while students upload and submit
    their work.
-   **Community:** Browse and interact with publicly shared portfolio
    files through likes and comments.
-   **Personal Organization:** Save favorite files, manage folders, and
    create or restore file backups.
-   **Notifications:** Keep students and instructors informed about
    relevant class and submission activity.

The application provides separate experiences for students and
instructors.

## Technologies Used

-   **Flutter** -- Framework used to build the application.
-   **Dart** -- Programming language used for application development.
-   **Firebase Hosting** -- Hosts and deploys the web application.
-   **Supabase** -- Used to demonstrate cloud storage and REST API
    integration, including uploading, retrieving, and managing files in
    cloud storage. Supabase is included as a demonstration of connecting
    an application to cloud services.
-   **Riverpod** -- State management.
-   **Inter and Lexend** -- Fonts used in the application.

The application integrates Supabase through the `supabase_flutter`
package, which provides access to Supabase services and APIs.
